---
title: "E116: An extern function can't have a body"
description: "What compiler error E116 means, and how to fix it."
order: 116
---

{/* Text from the turf-lang repository: docs/errors/codes/E116.txt. */}

`extern fn` doesn't define a function, it *announces* one that already exists somewhere else (usually in C). The code is not in your file, so there is nothing to write in `{ ... }`:

<Code title="Example">
```turf
extern fn malloc(size: int): ptr {       // no body allowed
    return null;
}
```
</Code>

Declare it with a semicolon instead:

<Code title="Example">
```turf
extern fn malloc(size: int): ptr;
```
</Code>

If you wanted to write the function yourself in Turf, drop the `extern`:

<Code title="Example">
```turf
fn my_alloc(size: int): ptr { ... }
```
</Code>

Run `turf --explain E116` in a terminal to read this again.
