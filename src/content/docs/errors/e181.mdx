{/* Generated by scripts/convert-errors.mjs from the diagnostic registry of turfc 2.3.0. */}

A warning, off unless its lint level is raised. Since TurfLang 2.3.

A `double` holds every whole number exactly only up to 2^53 (9007199254740992). An `int` goes up to 2^63 - 1, so converting a large one to `double` -- with `to double`, or by storing it into, passing it as, or returning it as a `double` -- rounds away its last digits:

<Code title="Example">
```turf
fn main(): int {
    mut big: int = 9007199254740993;
    mut d: double = big to double;   // WARNING (E181, when turned on): 9007199254740992.0
    printline(d);
    return 0;
}
```
</Code>

The warning is not shown when the compiler can prove the value is within +-2^53, for instance a constant or a literal that converts exactly.

This check is opt-in: it starts at `allow` and stays a warning in every version. Turn it on with `turf build --warn E181` (or `[lints] E181 = "warn"` in turf.toml) for code where exact large integers matter.

Run `turf --explain E181` in a terminal to read this again.
