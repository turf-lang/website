## How to use this page

A compiler error looks like this. The code (**E060**) is in square brackets on the first line:

<Diagnostic file="apples.tr">
```turf
fn main(): int {
    immut apples = 3;
    apples = 4;
    return 0;
}
```
```text
apples.tr (1 error)

── error at line 3, col 12 [E060 · declaration]

  Oops! You can't change the value of 'apples' because it's immutable.
  Note: declared immutable here (line 2, col 5)

  Hint: If you need to change its value later, declare it with 'mutable' instead of 'immutable'.

  3 │     apples = 4;
    │            ^ Here!

  Run `turf --explain E060` for more details.
```
</Diagnostic>

Find the code below, or run `turf --explain E060` in a terminal. The command line and the diagnostic format are described in [CLI & Diagnostics](/docs/tooling/cli-and-diagnostics/#part-2--diagnostics-and-error-codes).
