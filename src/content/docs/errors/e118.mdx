---
title: "E118: Statements have to live inside a function"
description: "What compiler error E118 means, and how to fix it."
order: 118
---

{/* Text from the turf-lang repository: docs/errors/codes/E118.txt. */}

A Turf file can declare things at its top level -- functions, structs, enums, imports, `extern` bindings, `export immut` constants -- but it can't *do* anything there. Statements (a call, an assignment, a variable, a `return`, an `if`) must be inside a function.

<Code title="Example">
```turf
import io;

io::printline("hello");          // a call, outside any function

fn main(): int { return 0; }
```
</Code>

Move it into `main`, which is where a program starts:

<Code title="Example">
```turf
import io;

fn main(): int {
    io::printline("hello");
    return 0;
}
```
</Code>

If a file has statements at the top level because it was meant to be a script, wrap them in `fn main(): int { ... return 0; }`.

Run `turf --explain E118` in a terminal to read this again.
