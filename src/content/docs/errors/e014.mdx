---
title: "E014: I don't recognize that word here"
description: "What compiler error E014 means, and how to fix it."
order: 14
---

{/* Text from the turf-lang repository: docs/errors/codes/E014.txt. */}

Turf expected a real keyword at this spot in your code -- something like `if`, `while`, `struct`, or `return` -- but the word it found isn't one of Turf's actual keywords. This is almost always a small typo.

<Code title="Example">
```turf
if x > 0 {
    return x;
}
```
</Code>

If you accidentally typed it wrong:

<Code title="Example">
```turf
iff x > 0 {   // typo! Turf doesn't know the word "iff"
    return x;
}
```
</Code>

The good news is Turf usually already knows what you meant and will suggest the real keyword right in the error message, so you can just fix the spelling and keep going.

If you're not sure what the actual keyword should be, it's worth glancing at a piece of working Turf code with a similar structure -- `if`/`elseif`/`else`, `while`, `for ... in ... step`, `struct`, `enum`, `fn`, `return`, `mut`/`immut`, and a handful of others are the reserved words Turf understands. Once the spelling matches one of those exactly, you're all set.

Run `turf --explain E014` in a terminal to read this again.
