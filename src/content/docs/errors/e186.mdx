---
title: "E186: Every way out of a loop comes after a call that ends the program"
description: "What compiler warning E186 means, and how to fix it."
order: 186
---

{/* Generated by scripts/convert-errors.mjs from the diagnostic registry of turfc 2.2.0. */}

A warning, off unless its lint level is raised. Since TurfLang 2.3.

Each way out of this loop that can be taken passes a call that never returns -- `sys::panic`, `sys::abort` or `sys::exit` -- so the code after the loop never runs:

<Code title="Example">
```turf
fn find(limit: int): int {
    mut j: int = 0;
    while true {             // WARNING (E186 at `warn`)
        j += 1;
        if j > limit {
            sys::panic("too far");
            break;           // never reached
        }
    }
    return j;
}
```
</Code>

If the loop is meant to stop, let it leave before the call:

<Code title="Example">
```turf
fn find(limit: int): int {
    mut j: int = 0;
    while j <= limit {
        j += 1;
    }
    return j;
}
```
</Code>

If ending the program is the intended way out, the `break` after the call is dead code: remove it and write the loop as `while true`. This warning starts at `allow` in 2.3: turn it on with `turf build --warn E186` (or `[lints] E186 = "warn"` in turf.toml).

Run `turf --explain E186` in a terminal to read this again.
