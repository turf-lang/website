---
title: "E073: An exponent marker with nothing after it"
description: "What compiler error E073 means, and how to fix it."
order: 73
---

{/* Text from the turf-lang repository: docs/errors/codes/E073.txt. */}

A `double` literal can use scientific-notation shorthand -- an `e` or `E`
followed by the power of ten to multiply by:

<Code title="Example">
```turf
mut avogadro: double = 6.022e23;
mut tiny: double = 1.5e-3;      // 0.0015
mut big: double = 1E+10;        // 10000000000.0
```
</Code>

The letter `e`/`E` always has to be followed by an actual exponent: an
optional `+` or `-`, then at least one digit. Once Turf sees `e`/`E` right
after a number, it commits to reading an exponent -- it will never quietly
reinterpret it as something else, so leaving it unfinished is always an
error rather than the number just ending early:

<Code title="Example">
```turf
mut x: double = 1.5e;    // ERROR: nothing after 'e'
mut y: double = 1.5e+;   // ERROR: '+' with no digit after it
mut z: double = 1e_5;    // ERROR: '_' can't be the first thing after 'e' either
```
</Code>

The fix is to either finish the exponent:

<Code title="Example">
```turf
mut x: double = 1.5e3;   // 1500.0
```
</Code>

...or, if you didn't mean to write an exponent at all, remove the `e`.

Run `turf --explain E073` in a terminal to read this again.
