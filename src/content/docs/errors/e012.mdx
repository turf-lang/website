---
title: "E012: You wrote code that comes right after a return, so it can never run"
description: "What compiler error E012 means, and how to fix it."
order: 12
---

{/* Text from the turf-lang repository: docs/errors/codes/E012.txt. */}

Once a function hits `return`, it's done -- control leaves right there and nothing else in that same block gets a chance to execute. Turf noticed a statement sitting right after a `return` (or `break`/`continue`) in the same block, which means that statement is dead code: it's there in your file, but the program can never actually reach it.

Here's the mistake:

<Code title="Example">
```turf
fn example(): int {
    return 5;
    io::printline("this never prints");
}
```
</Code>

That `printline` call looks perfectly normal, but the function already returned on the line above it, so it will never run -- not once, no matter what.

If that statement wasn't meant to run at all, just delete it. If you actually wanted it to happen, move it to BEFORE the `return`:

<Code title="Example">
```turf
fn example(): int {
    io::printline("this prints now");
    return 5;
}
```
</Code>

This one's easy to run into when you're moving code around while editing a function -- a quick reread of the lines right after a `return`/`break`/`continue` usually makes it obvious which case you're in.

Run `turf --explain E012` in a terminal to read this again.
