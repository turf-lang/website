---
title: "E167: Dividing by a literal zero"
description: "What compiler error E167 means, and how to fix it."
order: 167
---

{/* Text from the turf-lang repository: docs/errors/codes/E167.txt. */}

`/` or `%` with a literal `0` on the right is a division by zero, and it will crash the program when it runs:

<Code title="Example">
```turf
fn main(): int {
    immut n: int = 10;
    return n / 0;        // WARNING: division by zero
}
```
</Code>

Turf catches this when it can see the zero in your source. The right-hand side should be the real divisor. If it can legitimately be zero at run time, check for that first:

<Code title="Example">
```turf
fn main(): int {
    immut n: int = 10;
    immut d: int = 2;
    if d == 0 {
        return 1;
    }
    return n / d - 5;
}
```
</Code>

This warning only looks at literal `0` and `0.0`. A divisor that turns out to be zero only at run time is not caught, so a check like the one above is still the right habit.

This is a warning, not an error -- compilation still succeeds. To silence it for a whole build, set its lint level to allow: `turf build --allow E167` (or `[lints] E167 = "allow"` in turf.toml).

Run `turf --explain E167` in a terminal to read this again.
