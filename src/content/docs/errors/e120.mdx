---
title: "E120: That loop form isn't supported"
description: "What compiler error E120 means, and how to fix it."
order: 120
---

Turf has two kinds of `for` loop, and they take different shapes:

<Code title="Example">
```turf
for i in 0..10 step i += 1 { ... }          // a counting loop: ONE variable and a range
for value in numbers { ... }                // for-each over an array
for (index, value) in numbers { ... }       // for-each that also gives you the position
```
</Code>

The `(index, value)` pair only makes sense when you walk an array, because a range like `0..10` *is* the index -- there is no second thing to bind:

<Code title="Example">
```turf
for (i, x) in 0..10 { ... }                 // not supported
```
</Code>

Pick the form that matches what you are looping over: a range gets a single variable; an array can get one or two.

Run `turf --explain E120` in a terminal to read this again.
