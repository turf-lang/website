{/* Generated by scripts/convert-errors.mjs from the diagnostic registry of turfc 2.3.0. */}

A warning, off unless its lint level is raised. Since TurfLang 2.3.

An `import` that nothing in its file uses -- no `module::name`, no imported name, no method of one of the module's types -- only slows the build and misleads the reader:

<Code title="Example">
```turf
import math;   // WARNING (E179 at `warn`)

fn main(): int {
    printline(2);
    return 0;
}
```
</Code>

The compiler's `Fix:` removes the line. The prelude modules (`io`, `math`, `strings`, ...) are always available, so importing one of them again is never reported.

This warning starts at `allow`: turn it on with `turf build --warn E179` (or `[lints] E179 = "warn"` in turf.toml).

Run `turf --explain E179` in a terminal to read this again.
